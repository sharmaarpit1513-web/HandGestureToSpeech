# GestureSpeak 🎤✋

GestureSpeak is a real-time hand gesture recognition system that translates hand gestures into spoken output using computer vision and modern web technologies.

---

## 📌 Problem Statement
Individuals with speech or hearing impairments often face challenges in real-time communication. Existing solutions are either hardware-dependent or lack real-time responsiveness.

---

## 💡 Solution Overview
GestureSpeak uses a webcam to capture hand movements, detects hand landmarks, recognizes predefined gestures, and converts them into audible speech instantly through a browser-based interface.

---

## 🚀 Features
- Real-time hand gesture detection
- Gesture-to-speech conversion
- Browser-based (no external hardware required)
- Clean and interactive user interface
- Works with standard webcams

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- MediaPipe Hands (Google)
- Web Speech API
- Canvas API

---

## ⚙️ How It Works
1. Webcam captures live video
2. Hand landmarks are detected using MediaPipe
3. Gestures are classified
4. Corresponding text is generated
5. Text is converted into speech output
